# 金鱼 H3 参考视频精度

Pocket 识别包含 `MiniMaxH3ReferenceToVideo` 和 `SelfLiftH3Sampler` 的应用后，自动显示「参考视频精度」。已有的金鱼应用不必重新打包；更新 Pocket 并同步应用即可。

| 选项 | 参考画面的短边上限 |
| --- | --- |
| 省显存 | 320 像素 |
| 试跑 | 384 像素 |
| 精细（默认） | 512 像素 |
| 原始参考 | Pocket 不额外缩放，沿用模型自身处理 |

这相当于给模型看一份缩小的参考小样，减少参考条件的像素、潜变量和注意力计算。最终成片的分辨率仍由「视频分辨率」控制；原素材文件、参考片段的起点、时长、帧率、声音和编号均保留。小素材不会被放大，极端宽高比另有限制长边为该档短边的四倍，模型随后执行自身的网格对齐。

实现使用 ComfyUI 核心 `GetImageSize → ComfyMathExpression → ImageScaleBy`，只接到 H3 的参考视频输入，不接到输出或参考图片。按真实帧尺寸计算比例，兼容没有宽高元数据的旧上传记录。视频在 CPU 中加载和缩小；高分辨率素材解码时仍会短暂占用较多系统内存。此设置主要减少模型处理参考视频的负担，不会缩小主模型权重，也不保证完全不用系统内存。

默认使用 512；需要较低负担的预览时选择 384 或 320。相同素材、种子、提示词和其他参数下比较耗时与效果，不能把像素减少比例直接当成总显存或耗时减少比例。

参考了 [Tomiigo 的 H3 工作流](https://github.com/Tomiigo/minimax-h3-16gb/blob/main/examples/workflow_api.json) 在参考视频进入 H3 前先缩小的方式。Pocket 按原比例缩放并增加精度选择。
